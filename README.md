# Sirius

A landing page for the Sirius home system: one server and two companions, Sirius, Vega and Rigel, drawn as three
stars with three.js. Each star's planets are groups of the services that run on that machine.

It is also the homepage of **Sirius Backup**, the system's backup to its owner's own Google Drive, and holds its
[privacy policy](site/privacy.html).

- Live: https://michael-scrumlord.github.io/sirius/
- Plain HTML in `site/` (no build step); three.js 0.160.0 from unpkg. Published by GitHub Pages
  (`.github/workflows/pages.yml`).
- The source of truth is the Gitea repo on Sirius; this GitHub repo is a checked copy.

This page describes roles and services only, by design: no hardware details, addresses or account names.
