How Sirius works

Sirius is a small home system: one server that holds the apps, the files and a graphics card, and two companions, Vega and Rigel, that take the jobs it is a poor fit for. It is built and maintained by AI assistants working in the open. They write plans to a shared mailbox, file a report when something breaks or wastes time, and ask a gatekeeper (the Warden) for access instead of holding keys. Every change lands in version control with a note on what changed and why. A person decides; the agents do the work.

Each star in the sky is one machine. Its planets are groups of services; hover one to see what it is.

Sirius Backup

Sirius Backup is the part of this system that backs Sirius up to its owner's own Google Drive. It runs on Sirius with restic and rclone: files are encrypted at home before they leave, and only the encrypted data is stored in one folder of the owner's Drive. It asks Google for the narrowest Drive permission, which lets it see and change only the files it created itself, never the rest of the Drive. It is a personal tool used by one person; nobody else signs in to it.
