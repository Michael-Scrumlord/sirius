Privacy policy

For Sirius Backup, the backup tool of the Sirius home system, and for this website. Last updated 26 October 2026.

Who uses Sirius Backup

Sirius Backup is a personal tool. It runs on one home server and is used by its owner only. It is not offered to anyone else, and nobody else signs in to it.

What it accesses in Google Drive

It asks for the narrowest Google Drive permission (drive.file): it can see, create, change and delete only the files it created itself, in one folder of the owner's Drive. It cannot see any other file in the Drive, and it does not read the owner's profile, email or contacts.

What it stores

Backups of the home server, encrypted on the server before they are uploaded (restic). The encryption key stays at home; Google stores only encrypted data. Nothing is stored anywhere but the owner's own Drive.

Sharing

Data from Google APIs is not shared with, sold to or used by anyone, and is not used for advertising or to train models. Sirius Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and removing data

Backups are kept in the owner's Drive until the owner deletes them. Access can be withdrawn at any time at myaccount.google.com/permissions.

This website

This site sets no cookies and has no analytics or tracking. It is hosted by GitHub Pages and loads the three.js library from the unpkg content network; those services see the usual request details (such as your IP address), under their own policies.
